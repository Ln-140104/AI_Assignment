# Data

## raw/

Immutable copies of supplied assignment evidence.

## processed/

Generated datasets and intermediate artifacts.

This directory should contain reproducible outputs rather than
manually edited files.

## external/

External datasets used during the investigation.

External datasets should be downloaded through reproducible
scripts where practical rather than committed directly to the
repository.

## Data Integrity Principle

Raw supplied evidence must never be modified.

Derived datasets must have a documented generation procedure.
